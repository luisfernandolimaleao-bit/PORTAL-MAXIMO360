# Portal de Apoio ao Corretor — Maximo 360

Portal web desenvolvido para apoiar corretores de saúde da assessoria Maximo 360, com foco nos planos Bradesco Saude e SulAmerica.

## Acesso ao Portal

| Portal | Link |
|--------|------|
| Bradesco Saude | [consultabradsaude.web.app](https://consultabradsaude.web.app) |
| SulAmerica | [consulta360sulamerica.firebaseapp.com](https://consulta360sulamerica.firebaseapp.com) |

**Acesso para demonstracao:** `demo@git.com.br` — Senha: `Git2026`

## Funcionalidades

- Login com autenticacao Firebase Authentication
- Comparador de planos com exportacao em PDF
- Busca de rede credenciada (413 hospitais, 178 cidades)
- Calculadora de coparticipacao
- Documentacao comercial para corretores

## Tecnologias utilizadas

- HTML, CSS e JavaScript
- Firebase Authentication e Hosting
- Desenvolvimento assistido com Inteligencia Artificial
